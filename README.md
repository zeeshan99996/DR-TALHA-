# Talha Clinic & Maternity Home

Website for Talha Clinic & Maternity Home — 24/7 Emergency Care.

## Features
- 24/7 Emergency Services, Laboratory, Pharmacy, Ultrasound, Vaccination & X-Ray
- Doctor profile and clinic information
- Lightweight Node.js HTTP server (`server.js`)

## Running Locally
```bash
node server.js
```
Then open `http://localhost:3000` in your web browser.
